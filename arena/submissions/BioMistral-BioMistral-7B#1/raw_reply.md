This task is a 1v1 variant of the "Control of a distributed file system" task. The task is to implement a resource allocation policy that maximizes the cumulative reward, while considering the cost of rebuilds. The policy must be implemented in Python and return a value in the range of 0 to 3, which corresponds to the index of the rebuild rate to be chosen. The performance of the policy is measured against the optimal policy and a rule-based baseline policy.
